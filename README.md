# 坦克大战 Tank Battle

一个使用纯 HTML、CSS 和 JavaScript 实现的浏览器坦克大战游戏。

## 在线体验

直接在浏览器中打开 `index.html` 即可开始游戏。

## 操作说明

| 按键 | 功能 |
|------|------|
| `W` / `↑` | 向上移动 |
| `A` / `←` | 向左移动 |
| `S` / `↓` | 向下移动 |
| `D` / `→` | 向右移动 |
| 鼠标移动 | 瞄准 |
| 鼠标左键 | 射击 |
| 空格键 | 暂停 / 继续 |

## 游戏特色

- 🎮 经典的俯视视角坦克射击玩法
- 🤖 敌方坦克 AI：追踪玩家、保持战斗距离、利用掩体
- 🧱 可破坏视野的墙壁障碍物
- 💥 爆炸与火花粒子特效
- 🌊 随波次递增的难度和敌人数量
- ❤️ 生命值与得分系统

## 本地运行

```bash
git clone https://github.com/YOUR_USERNAME/tank-battle-html.git
cd tank-battle-html
# 用浏览器打开 index.html
```

## 技术栈

- HTML5 Canvas
- 原生 JavaScript（无外部依赖）
- CSS3
